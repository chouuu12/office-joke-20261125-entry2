One short joke about office life, at most 200 characters, written as a single line: the coffee machine has worn an "out of order" sign for so long that three of my colleagues were hired after it.

## Run it

```sh
node main.ts
```

`main.ts` reads the joke from `line.txt`, validates it against the competition gate (1–200 characters, single line, not only whitespace) and writes it byte-exact to `/output/entry.txt`. Set `OUTPUT_DIR` to run it locally against a scratch folder instead of `/output`.
